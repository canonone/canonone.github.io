Aerosub Solutions · Backend Developer & DevOps Engineer

Multi-tenant SaaS inspection platform for marine and industrial asset management, used by enterprise clients in oil and gas. I built and run the backend: modular NestJS services, RBAC with org-scoped guards, a multipart S3 pipeline for 100MB+ 3D models and panoramas, and BullMQ jobs for PDF reports.

Problem I solved: report generation that couldn't scale

PDF reports with high-quality images were generated with Puppeteer and a Chromium extension. Each worker kept a Chromium instance alive inside the Node process. That used enough RAM to cap us at one report at a time on our instance size. Clients needed hundreds of reports, so jobs queued behind each other, and adding RAM wasn't cost-effective.

I migrated generation to Gotenberg, a Dockerized document conversion API. It starts Chromium for each request and shuts it down afterwards, and it runs as a separate service we can scale on its own. That removed the one-at-a-time bottleneck, and report generation now keeps up with client demand.

QR Pay

DevCareer × Nomba Hackathon 2026

Solo entry · Designed and built end to end

A payment infrastructure layer for QR-code payments, built on Nomba's payment API. The backend is a NestJS/TypeORM/PostgreSQL monorepo with a Next.js frontend.

Problem I solved: keeping payments and orders consistent

Payment callbacks can arrive late, twice, or not at all. I verify every webhook with an HMAC-SHA256 signature and process payments and orders asynchronously with BullMQ and Redis. A reconciliation engine keeps payment state and order state in agreement. I also wrote the system design document, API docs and PRD.
